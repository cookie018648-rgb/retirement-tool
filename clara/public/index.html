Clara — 投稿案メーカー

お店やサービスの説明を貼るだけで、Instagram の投稿案を3パターン作ります。

文章を作るのに Anthropic の API を使います。 console.anthropic.com でキーを作って、貼り付けてください。（sk-ant- で始まる文字列です）

連携済み

登録すると、作った投稿案をこの画面から直接Instagramに出せるようになります。 あとから設定してもかまいません。

できるだけ具体的に書くほど、投稿案も具体的になります。
例：東京・蔵前のシングルオリジン豆専門の自家焙煎ロースタリー。週替わりで3種類の豆を店頭で焙煎している。
